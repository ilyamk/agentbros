# Reference inbox

Drop reference films here, each with an optional `<name>.md` beside it holding the link, the segment and what to learn. Everything in this folder except this README is git-ignored: films and their notes stay on your machine.

Add one with `pnpm ref:add --file design-reference/library/inbox/<name>.mp4 --id <id>` (rights default to `study-only` here), then follow [contributing references](../../../docs/contributing-references.md).
