# Scene Storyboard Template

One worked structure, not a rule. Animations and transitions below are examples of choices.

## Video Structure (5-Scene Product Promo)

### Scene 1 — Hook (3-4s)
**Goal:** Stop the scroll. Ask a provocative question or make a bold claim.
```
┌─────────────────────┐
│                     │
│   ─── accent ───    │
│                     │
│   STOP WASTING      │
│     TIME            │
│                     │
│   There's a better  │
│      way            │
│                     │
└─────────────────────┘
```
- Type: TitleScene
- Animation: Line draws in → headline slides up → subtext fades in

### Scene 2 — Problem (4-5s)
**Goal:** Describe the pain point the audience relates to.
```
┌─────────────────────┐
│            ● ● ● ●  │
│            ● ● ● ●  │
│  ┌─────────────────┐ │
│  │ The Problem     │ │
│  │                 │ │
│  │ Manual video    │ │
│  │ creation doesn't│ │
│  │ scale           │ │
│  └─────────────────┘ │
│                     │
└─────────────────────┘
```
- Type: FeatureScene
- Animation: Card scales in → headline slides from left → subtext fades

### Scene 3 — Solution / Product (4-5s)
**Goal:** Introduce the product as the hero.
```
┌─────────────────────┐
│                     │
│                     │
│     ○ (glow)        │
│   AI VIDEO          │
│   CREATOR           │
│                     │
│   One click.        │
│   Every platform.   │
│                     │
└─────────────────────┘
```
- Type: ProductScene
- Animation: Glow pulses → name bounces in → tagline slides up

### Scene 4 — Features (4-5s)
**Goal:** Show 2-3 key features or benefits.
```
┌─────────────────────┐
│                     │
│  ┌─────────────────┐ │
│  │ Powered by AI   │ │
│  │                 │ │
│  │ ElevenLabs      │ │
│  │ voice •         │ │
│  │ Smart layouts • │ │
│  │ Auto-export     │ │
│  └─────────────────┘ │
│                     │
└─────────────────────┘
```
- Type: FeatureScene
- Animation: Same as Scene 2 with different content

### Scene 5 — CTA (3-4s)
**Goal:** Tell the viewer what to do next.
```
┌─────────────────────┐
│                     │
│   GET STARTED       │
│   FREE              │
│                     │
│  ┌─────────────────┐ │
│  │  Try It Free →  │ │
│  └─────────────────┘ │
│                     │
│   No credit card    │
│   required          │
└─────────────────────┘
```
- Type: CTAScene
- Animation: Headline bounces → button slides up + pulses → subtext fades

## Transitions Between Scenes
Choose per cut from the idea and rhythm, for example:
- Scene 1→2: hard cut on the first word of the problem
- Scene 2→3: shape wipe from the card into the product glow
- Scene 3→4: match cut on the product name
- Scene 4→5: whip into the CTA; the last frame holds as thumbnail and loop frame
