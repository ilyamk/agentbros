Read [motion decisions](references/motion-decisions.md) when choosing emphasis and timing, and [motion grammar](references/motion-grammar.md) for the repertoire by moment and meaning: the camera, crossing a boundary, what arrives and how, type as performer, landing and leaving, building a frame, the film's rhythm. Each entry names its primitive or technique card. Pace comes from the music and the reference's numbers. When a cut risks reading as slides, check both causes in [carry and rhythm](references/carry-and-rhythm.md): a metronome cadence and beats that replace each other.

**Bespoke film** (`brief.renderMode: "bespoke"`): follow the [motion-director](../../agents/motion-director.md) for the plan on paper and the [motion-engineer](../../agents/motion-engineer.md) for the build. The plan follows `MotionPlanSchema` in `src/types/creative.ts`. Primitives are listed in [src/motion/AGENTS.md](../../../src/motion/AGENTS.md).

**Template mode:** use `pnpm video:recipe --action list` to inspect template purposes, samples and style packs. Component/props contracts live in `src/types/templates.ts`; registry metadata lives in `src/lib/templates/registry.ts`. Do not duplicate API names or prices in this skill. Produce `pipeline/motion-plan.json` with sceneId, template ID/version, validated props, purpose, reveal/hold/exit timing, visual proof source and reason for each emphasis.

In either mode, one scene should advance one argument. A data claim requires sourced values; a decorative count-up does not supply evidence.

For a year chart, optionally declare each point's `domain:{kind:'year-v1',year:2019}` and a domain-label annotation's explicit matching binding. All series on a typed shared axis require consistent positional years and canonical visible year labels. Pipeline findings use the renderer's actual targets, including series precedence and default annotation series0. Freeform or untyped charts remain unverified; inspect the real frame and substantiate the quantity and source independently. Remove an unsupported annotation without inventing replacement data.

Declare percentage meaning explicitly when available: `return-percent-v1` measures a return, while `population-outperformed-percent-v1` measures a cohort share. Name subject, period, basis and method; population share also names cohort and comparator. A bound callout must format its actual hero-series point exactly. A visible `95%` cannot prove that these different quantities agree. Preserve the supplied dataset and attach the existing owning workflow claim to a precise local normalized source record through the quantity/source contract. Missing correspondence remains unverified; illustrative records do not substantiate a real statistical claim.

Prefer existing primitive/block/scene entries. `scene.template` selects a validated registered renderer; caption templates overlay the scene's visual. Registered templates and style profiles are opt-in and currently offer frame-driven fade, scale and clip motion; write a custom frame-driven component when the idea needs more. Design tokens are defaults for typography; safe zones remain technical guidance. Preview via `pnpm video:recipe --action template-preview --template <id> --project <new-id>` and the generic renderer.

Review frames at reveal, reading hold and exit in each target format, and motion from strips of consecutive frames (`pnpm motion:strip --input FILM --output STRIP --start-sec A --end-sec B --diff`): a contact sheet hides motion. Keep long Russian phrases readable by rewriting into lines or changing layout before shrinking text. Runtime API/schema checks and creative review are different evidence; a passing validator does not demonstrate a strong hook. Maintain leaf-agent depth constraints from AGENTS.md.

For a procedural interaction that needs translating spheres, read [bounded sphere bakes](references/sphere-bakes.md). Use the explicit owned solver and installed trusted Blender route, inspect contact frames and import checked candidates. More complex physics needs a different validated workflow; a rendered collision does not establish a real-world physical claim.

For trusted local HTML/Hyperframes footage, choose an explicit supported profile in the [capture contract](../../../docs/html-capture.md) and use `pnpm capture:html --help`. The genuine native media profile can opt into macOS `decoded-source-proxy-v1` for AAC/embedded audio/VFR. Source-time selection follows the original rational frame intervals; the private 30fps ordinal proxy is a picture store, never a replacement timing reference. Keep originals and checked capture receipts, review selected/terminal frames, then import the verified output as an asset. Unsupported clocks/automation/GPU modes require another validated route rather than a nominal-fps guess.

Static external compositions use the explicit `static-local-tree-v1` choice with the separately pinned tree runtime and native media profile. Declare the literal zero-start root, unique child sources/IDs and bounded ancestor windows before capture. Review random/repeated frames and media boundaries; retain receipts and originals when importing. The three-level static subset does not authorize dynamic children, repeated source instances, arbitrary automation or hostile code.
