# Freemium catalogue routing

Use `pnpm resources --action route --task TASK` first. Tasks: educational-archive, product-graphics, sound-effects, motion-design, three-dimensional. This read-only action makes no catalogue request and grants no rights. `--action providers` reports implemented metadata APIs separately from manual catalogue routes; `--action catalog --provider kenney|ambientcg|rive --query "..."` returns an official catalogue link and manual instructions, not search results.

## Stock photos and video (Unsplash, Pexels, Pixabay)

One adapter per source (`src/lib/resources/stock/`), one ranked search. `--action search --provider auto --kind image|video --query "<action, framing, light>" --format vertical|square|landscape [--zoom 1.3] [--color brown] [--orientation portrait] [--safe] --output shots.json` asks every source with a key and ranks the union for the frame: resolution against format and push-in (a file needing more than 1.5x is listed as `blocked: resolution`), aspect, words in title/tags and dominant colour. `metadata.providers` reports each source's status, notes on filters it could not apply, requests (network vs cached) and remaining quota.

- Which source: Unsplash for curated high-resolution stills (photos only; `--collections`, `--topic`; 50 requests/hour on a demo key, so search deliberately). Pexels for clips and stills. Pixabay for clips up to 4K, illustrations and vectors (`--image-type`, `--category`, `--editors-choice`); its stills stop at 1280 px without approved full API access, which the ranking shows.
- A series with one look: `--same-author-as <candidate.json>` follows that photographer (native on Unsplash, filtered locally elsewhere).
- Acquire: `--action acquire --candidate shots.json --index N --project ID --format vertical [--zoom 1.3] [--credit]`. It downloads the size the frame needs (Unsplash resizes from the raw file keeping `ixid`; videos take the smallest file that fills the frame), refuses one too small unless `--allow-upscale`, reports the download to Unsplash first as its API requires, and writes the receipt.
- Rules kept by the code: Pixabay searches are cached 24 hours and files are always downloaded; Unsplash previews are its hotlinked URLs and links carry the utm referral; keys never enter cache keys or disk. Licences allow commercial edits without credit and block standalone resale and implied endorsement.

## Source-specific decisions

- NASA: scientific/archive images, video and audio. `--action search --provider nasa --query "..." --kind image --page 1 --limit 10` makes a metadata request only when online discovery is authorised. Inspect a saved candidate to retrieve manifest metadata. A unique `~orig` file is recorded separately from preview; multiple/missing originals require manual selection. There is no automatic media acquisition. Every search candidate starts with unknown/unconfirmed rights. Check the individual source page, third-party material, people/logos, credit, endorsement and AI guidelines; never relabel the catalogue CC0. The current route blocks advertising, endorsement and standalone resale even after generic source confirmation. [API specification](https://images.nasa.gov/docs/images.nasa.gov_api_docs.pdf), [media guidelines](https://www.nasa.gov/nasa-brand-center/images-and-media/).
- Kenney: UI art, textures/models and sound packs for product motion and local simulations. Check the actual pack and its licence file; asset-page CC0 does not include branding. Manually download/extract a permitted original; no implemented catalogue API or archive extraction. [Catalogue](https://kenney.nl/assets), [terms](https://kenney.nl/support).
- ambientCG: original PBR textures/maps/HDRIs/models for 3D work. Its documented licence covers assets and preview images under CC0. Select original resolution/maps and retain source evidence. The platform implements a manual route, even though upstream documents an API; it does not claim an integrated ambientCG client. [Catalogue](https://ambientcg.com/list), [licence](https://docs.ambientcg.com/license/).
- Rive: visual motion references and permitted file exports. Check the creator's individual file licence, runtime/export needs and account plan. Free editor access does not prove a commercial file licence or video export availability. Import an explicitly permitted original export manually; no Rive runtime/capture adapter is implemented by this route. [Marketplace](https://rive.app/marketplace/), [plans](https://www.rive.app/pricing).

## Reviewable manual import

Save a `ResourceCandidate` JSON with the exact asset page, provider, kind, title/author, `acquisition: "manual"`, media/tags/cost and rights evidence. Discovery candidates should use `verifiedAtSource: false` until actually checked. Do not use the catalogue home page as evidence for a selected asset.

Use `--action confirm --candidate candidate.json --source-url EXACT_ASSET_PAGE --licence CC0 --licence-url LICENCE_URL --output confirmed.json` only after inspecting that source. Then `--action rights --candidate confirmed.json --commercial --advertising --placements youtube` for the intended usage, and `--action acquire --candidate confirmed.json --project ID --source-file /absolute/permitted-original.png`. This retains original bytes, manifest provenance and a project licensing receipt. Acquisition is an explicit mutation and must remain within the user's authorisation. Unrecognised/conditional licences require a properly reviewed candidate record; the generic confirmation helper does not manufacture permission.

Native TikTok/Meta/YouTube music stays track/territory/channel-specific; reconfirming a source preserves known placement restrictions. No downloaded popular track, search result or paid account grants universal advertising rights. Local tests establish adapter behaviour, not live source access, rights clearance or audience success.
