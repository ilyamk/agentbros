# Local craft evaluation

Use the same supplied inputs for the baseline and proposed skill revision. Save skill version, project snapshot, decision artefact, rendered comparison and reviewer evidence. These cases require no model generation.

| Brief | Required decisions | Known failure that must be caught |
|---|---|---|
| UGC 20 seconds | Promise/payoff, 3 or fewer evidence changes, readable proof, consented source | Unsupported testimonial/claim or hook with no payoff |
| Product demo 30 seconds | Real label/packshot, action coverage, meaningful detail shot | Generated product logo mistaken for approved reference |
| Education 3 minutes | Chapter question, source/claim map, example and recap, keep qualifications | Invented chart data or removal of a caveat |
| Russian talking head | Calm word budget, one audio owner, source-mapped captions across fades | Double voice or caption drift after rate/trim |
| Music motion | Licensed/created music, motivated accents, readable typography | Unlicensed trend track claimed cross-platform cleared |
| Recorded recut | Protected spans, before/after context, reversible track-specific edits | A removed negation or unrelated track ripple |

Technical review is reproducible: validate schemas, compile exact timing, check budget reserves/unknown prices, inspect originals/hash/rights, render boundary frames and measure output sound. Creative review records a human judgement for clarity, shot purpose, continuity and emotional intent, with specific examples. A passing schema or an automated score cannot substitute for that judgement. Outcome metrics require real measured data; none are fabricated in local evaluations.

## Reproducible four-workflow comparison

For product-ad, education, recording-edit or shorts-series, use the [offline craft evaluation contract](../../../../docs/craft-evaluation.md). Discover rubric IDs through `pnpm exec tsx scripts/craft-evaluation.ts --action rubric`, then pin actual skills, shared originals, configuration, craft decisions and outputs in a version-1 manifest. Evaluate baseline/candidate read-only, retain failures, and bind targeted repairs and human observations to returned fingerprints. Fixture observations stay pending; imported delivery evidence does not grant release approval. The runner checks existing workflow contracts rather than assigning artistic scores.
