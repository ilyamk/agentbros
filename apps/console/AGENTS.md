# Studio console UI — Agent Rules

Last updated: 2026-11-20

The browser half of the studio console ([guide](../../docs/console.md), [RFC 0004](../../docs/rfcs/0004-studio-console.md)): Vite, React 19, Tailwind v4, shadcn/ui on `radix-ui`. Not Remotion code: the determinism law does not apply, but every animation is a 150–250 ms CSS transition (`starting:` for enter), off under `prefers-reduced-motion`. Never imported from `src/`.

## Hosting rules (the server serves exactly `index.html`, `app.js`, `style.css` under a strict CSP)

- No inline script or style, no `data:`/`blob:` URLs, no fonts, CDNs or remote URLs; `pnpm console:build` verifies the bundle.
- `<style>` only with the `<meta name="csp-nonce">` nonce: `lib/nonce.ts` sets get-nonce's global at boot; pass `cspNonce()` to Radix `ScrollArea`/`Select` viewports. Dynamic colours go through the `style` prop (CSSOM), never a `<style>` element.
- No `eval`: `lib/zod-jitless.ts` is main.tsx's first import. No sonner and no `motion`.
- Side-effect-only imports are dropped (package.json `sideEffects` lists CSS only): register with a call.

## Rules

- 2026-11-18: every dropdown is `SelectField` (or the `Select` parts) from `components/ui/select.tsx`, the shadcn/Radix Select on the console tokens; no native `<select>`, whose option list the OS draws outside the theme. The trigger keeps the control's `id` and mirrors the value as `data-value`; an empty option value travels as a sentinel. Form fields fill their column (`w-full min-w-0`, label truncated), the popup matches the trigger width and stays inside the viewport. Tests pick options with `chooseOption`/`selectOptions`/`selectValue` (`test/utils.tsx`) and, in e2e, `choose`/`withOptions` (`e2e/select.ts`).
- 2026-11-18: checkboxes are `components/ui/checkbox.tsx` and visible range controls `components/ui/slider.tsx` (shadcn/Radix; name, value text and data attributes on the thumb via `thumb`); multi-line text is `Textarea`. Native `type="range"` stays only as the invisible seek overlay of the drawn audio waveform. Tests move sliders with `setSlider` (`test/utils.tsx`).
- 2026-11-18: collapsible blocks are `Disclosure` (`components/ui/disclosure.tsx`: native `<details>`, chevron, `card` or `plain`, `muted`); the summary text sits in a `span`. `html` has `scroll-padding-top` so anchors and focus clear the sticky app bar. Links and buttons carry no `aria-label` that hides their visible text: extra words go in `sr-only` after it (axe `label-content-name-mismatch`).
- 2026-11-18: API key rows stack descriptions above the full-width field controls. Fields are always visible. Paired tabs show disabled fields with empty values. Edit API keys opens the editor through the OS. Reveal and copy fetch one value.

- 2026-11-18: the shell's app bar (`shell/app-shell.tsx`) is sticky at every width; its right side holds `shell/github-button.tsx` (GitHub mark, "GitHub", star count) linking to `https://github.com/ilyamk/agentbros`. The browser never calls GitHub: `GET /api/github` (`src/lib/console/github.ts`) fetches the count server-side and caches it (1 h, 10 min after a failure, `stars: null`); the contract is in `src/lib/console/github-schema.ts` so no API address enters the bundle. Snapshot mode shows the link without a count.
- 2026-11-18: the repository URL lives once in `src/lib/console/github-schema.ts` (`GITHUB_URL`, `github.com/ilyamk/agentbros`); `lib/about.ts` builds licence links from it.
- 2026-11-18: the sidebar footer shows `© 2026 ILIA_AGI · BUSL-1.1 · v<version>`, and Settings ends with an "About and licence" card that holds the licence summary, the "as is" warranty disclaimer and links to the licence files. All constants live in `lib/about.ts`; the version is read from the root `package.json`. External links use `rel="noreferrer noopener"`, so they never copy the session token.
- 2026-11-18: Home card settings rename a project's display title or delete it after the user types its ID. The HTTP client uses authenticated project actions. Fixtures and snapshots omit the settings button.
- 2026-11-18: Remotion Studio on request (D21 amended): `ApiClient.studioStatus`, `studioOpen`, `studioStop` (`GET`/`POST /api/projects/<id>/studio`, `…/studio/stop`); open the returned loopback URL in a new tab from the click handler; the fixture client simulates it ([guide](../../docs/console.md#remotion-studio)).
- 2026-11-18: the project header's editing table (`shell/editing-table.tsx`) opens the Timeline page with `window.open(url, "_blank")` and no `noopener`, synchronously in the click, so the browser copies the sessionStorage token to the new tab; "Edit myself" opens the tab first, then pauses with `reason` starting `editing-table`, which alone shows the Timeline banner. The Studio launcher (`media/studio-action.tsx`, `studioStatus`/`studioOpen`/`studioStop` on `ApiClient`) opens a blank tab in the click, clears its copied sessionStorage, cuts its `opener`, then sets its location; one status request per client and project; e2e `e2e/editing-table.e2e.ts`.
- 2026-11-18: live journal events share the 50,000-event retention cap; media elements stay mounted on load failure so replacement sources retain event subscriptions.
- 2026-11-18: document tiles open `media/document-dialog.tsx`. The live API decides whether the user may edit the file, and a save refreshes the pending decision.

- 2026-11-18: `shell/hooks-banner.tsx` shows a banner at the top of every page while either harness's hooks are `missing` or `stale` (live clients only, not in snapshot mode). Its dialog explains why hooks matter, shows the status, has Check again, Install or Update (the click is the user's yes, after the plan and command are shown) and Close. Its close button hides it for good in this browser (`agentbros.console.hooksBannerDismissed` in localStorage). The banner, its dialog and Settings read one status through `shell/hooks-state.ts`; call `refreshHooks` after an install.

- 2026-11-20: step rail concepts on preview (`components/step-rail-concepts/`, [proposal](../../docs/console-steps.md)): `?rail=current|a|b|c|all&railData=live|every|simulate`, fixture `view-step-rail`. Their `rail-*` keyframes in `styles.css` are the one exception to the transition-only motion rule, `motion-safe:` only, until the user picks; then the winner replaces `step-rail.tsx` and the preview goes.

- Every UI string is a key in all three dictionaries (`i18n/i18n.test.ts` fails on a missing key, placeholder or plural form). User and agent text is shown as written, never translated; Markdown goes through `lib/markdown.tsx` (React elements only, no HTML).
- Status always pairs colour with an icon (`lib/status.ts`); text contrast WCAG AA in both themes.
- Decisions send the user's words verbatim; a consequential option shows the exact command first. Panels point to the pinned decision card and never decide themselves; the verdict is given only on `film.human`. Pools are shown blind (`view.film`, never authors). Ratings and frame comments (`panels/film/feedback.tsx`) never appear around the verdict player.
- Read-only modes: fixture `?fixture=<name>` (contract fixtures such as `view-film-build`, `view-footage`, `view-replica`, plus `cards`, `projects-response`; `&lang=`, `&theme=`; clock frozen, UTC) and snapshot mode (`api/snapshot.ts`, `lib/snapshot-mode.ts`: media as relative-path notes, no decisions).
- Notifications: `lib/notify.ts` sends a presence heartbeat and a browser `Notification` only when hidden; permission is asked only on a click. `#/projects/<id>/decision/<id>` focuses a card.
- Timeline: keep review:ui's element ids; review previews use the review file route (`api.fileUrl`), not `/media`.
- Tests: `pnpm console:test` (Vitest, jsdom); `RUN_CONSOLE_E2E=1 pnpm console:e2e` (Playwright against fixtures and a real server, `tests/helpers/console-*-server.ts`: screenshots at 1280 and 390 px, dark and light, into `out/qa/console/`; axe; strict-CSP run).
- Session (D15): no route serves the token back: the tab keeps it in sessionStorage (`api/session.ts`), a `#pair=` code is redeemed once (`POST /api/session/pair`), the stream is read with `fetch` and the header (`api/stream.ts`); the cookie loads media only; e2e `e2e/session.e2e.ts`.
- 2026-11-18: live console routes keep a stream for same-tab reconnects. A transient outage retries with the tab's session. A rejected session stops retries and waits for a fresh link in the same tab.
- Top bar and history: `shell/autonomy.tsx` (`policy` decisions; a wider grant shows the dry-run argv first), `shell/paid-jobs.tsx` (stop's per-job cancel), `shell/hooks.tsx` (`/api/hooks`, install after a confirm; status shared with the banner via `shell/hooks-state.ts`), `panels/generic/compare-versions.tsx` (`lib/line-diff.ts`); real-server e2e `e2e/gaps-server.e2e.ts`.
- 2026-11-17: complete through RFC 0004 WP16; `review:ui` opens only this console (the HTML-string client is gone), so review UI work happens here.
