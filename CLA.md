## How to sign

Read this agreement, then post this comment, as a new comment on Your pull request, from Your human GitHub account:

```
I have read the Individual Contributor Licence Agreement in CLA.md at commit COMMIT and I agree to it
for this and all my future Contributions to Agent Bros. Pictures.
Name: FULL NAME
GitHub or Git username: USERNAME
```

Replace `COMMIT` with the full 40-character hash of the current default-branch commit of https://github.com/ilyamk/agentbros (`git ls-remote https://github.com/ilyamk/agentbros.git refs/heads/main` prints it; in a clone of Your fork, `origin` is the fork, not this repository), `FULL NAME` with Your name and `USERNAME` with the GitHub account that posts the comment. The bot records the signature only when these match.

Alternatively, post a new comment on Your pull request, from Your human GitHub account, containing only this sentence:

```
I have read the CLA and I agree to it.
```

By posting it, You accept this agreement, as it reads in CLA.md on the default branch of https://github.com/ilyamk/agentbros when the bot records Your signature, for the Contribution in that pull request and all Your future Contributions to Agent Bros. Pictures. The bot records the default-branch commit and the CLA.md version at that time, and identifies You by the GitHub account that posts the comment.

If You sign on behalf of an organisation (section 1), name it in a separate comment on the same pull request.

The agreement then covers all Your later Contributions until You give written notice ending it for future Contributions. Contributions already made stay licensed.
