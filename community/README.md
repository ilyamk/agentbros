# Contributors

Profiles live in `contributors/<github-handle>.json`. Use `displayName`, HTTPS `links`, `bio` (up to 280 characters) and `credits` (up to 500 characters). Do not add private contact details.

The site computes contributions by category, authored blocks and showcase uses, films, reproduced benchmark bundles and instruction bytes removed. Badges recognise categories; profiles are alphabetical, with no ranking by pull-request count. Missing attribution is reported rather than guessed.

See [showcases and field reports](../docs/showcases.md).
