# Reference analyses

## What is valuable

Contribute structure-only analysis in `design-reference/library/` or `design-reference/techniques/` that a block or rule uses. Follow [contributing references](../../docs/contributing-references.md) and inspect `pnpm ref:contribute --help`.

## Not wanted

Third-party film frames, restricted media, unsupported timing claims or analysis with no use in a block, rule or named gap.

## Definition of done

Validate/redact through the reference contribution workflow; retain measured timing, technique function and source rights without private material. Identify the consuming block or rule.

## Evidence required

Structure-only analysis, rights evidence and leak-clean contribution output; link the resulting use.

- `pnpm typecheck`
