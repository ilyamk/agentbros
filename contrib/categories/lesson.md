# Generalised lessons

## What is valuable

Generalise a repeated cause from an applied upstream proposal into a rule or sensor. Follow `pnpm memory:upstream --help`; contribute the resulting leak-clean patch and evidence, not local memory.

## Not wanted

Personal memory, client names, one-off preferences as universal rules or unsupported claims of repeated failures.

## Definition of done

Preserve the proposal evidence and targeted test; inspect the destination area instructions and protected-path rules. Apply only the generalised change and keep private project artefacts local.

## Evidence required

Upstream proposal evidence showing the repeated cause and leak-clean text; run `pnpm leak:check` on the contribution.

- `pnpm typecheck`
