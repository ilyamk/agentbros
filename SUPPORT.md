# Support

Follow [installation](docs/install.md), run `pnpm preflight` and read the affected area's guide before asking for help. Search existing [issues](https://github.com/ilyamk/agentbros/issues) and [Discussions](https://github.com/ilyamk/agentbros/discussions).

Use Discussions Q&A for usage questions, Ideas for possible features, RFCs for large designs, Showcase for films and Benchmark for result discussion. File a [bug report](https://github.com/ilyamk/agentbros/issues/new?template=bug.yml) for a reproducible defect; include the commit, platform, failing command, expected/actual behaviour and a minimal fixture with private data removed.

Use the [contributor protocol](CONTRIBUTING.md) to offer a patch. Send vulnerabilities and prompt-injection or instruction supply-chain reports through [SECURITY.md](SECURITY.md). Report conduct concerns privately as described in [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md). Do not post credentials, local memory or private project material in support requests.
