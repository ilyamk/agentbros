# Looks & colour

Generated by `pnpm colour:looks --write-doc` from `src/lib/colour/looks.ts`; do not edit by hand.

Colour looks are grade files, not Remotion blocks: `colour:looks` applies them to footage with skin held and gated, `colour:grade` renders one, and `FilmFinish` (the `finish` column) adds grain, halation and bloom in the composition. Mood is valence and arousal on -1..1 by convention (brightness and warmth raise valence; saturation and contrast raise arousal), from colour-patch studies, not a measured emotion. Previews are on a synthetic test card: grey ramp, two hue sweeps, six skin tones on the skin line and four memory colours (sky, foliage, brand red, white).

Render the card previews locally with `pnpm colour:looks --card --output <dir>`; images stay out of git.

| Workflow                                                  | Command                                                                               |
| --------------------------------------------------------- | ------------------------------------------------------------------------------------- |
| Profile a reference into per-shot targets (colour script) | `pnpm colour:target --input <reference> --output <dir>`                               |
| Shortlist looks for its mood                              | `pnpm colour:looks --target <dir>/target.json --input <video> --output <dir>`         |
| Plan a mood per shot and solve bounded grades             | `pnpm colour:target --input <video> --mood "0:-0.6,0.1;12.4:-0.4,0.3" --output <dir>` |
| Import a licensed LUT, then try it as a look              | `pnpm colour:lut --add <file> --licence <id> --source <url> --project <id>`           |
| Hold the final film to the target                         | `pnpm colour:check --target <dir>/target.json --input <graded> --source <ungraded>`   |
