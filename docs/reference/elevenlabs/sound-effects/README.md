# ElevenLabs sound effects

Use `pnpm sfx:find` for existing sounds, `pnpm sfx:cues` for placement and `pnpm sfx:synth` for local synthesis. Paid generation uses `pnpm sfx:generate`.

Read [API reference](UPSTREAM.md), [MIT](LICENSE), [provenance](../README.md) and [production contracts](../../../audio-integrations.md).
