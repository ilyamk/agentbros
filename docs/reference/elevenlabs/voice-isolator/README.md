# ElevenLabs voice isolation

Use `pnpm audio:transform` with task `isolate`. Retain original media and source hash. Transcribe or align the derived audio separately; equal duration does not prove an unchanged source clock. Ingest and edit decisions remain bound to the original recording until the mapping is reviewed.
