# ElevenLabs text-to-speech

Use `pnpm generate:voiceover`. A pinned VoiceRef opts into timestamped immutable takes. Use `pnpm voices` for discovery and `pnpm voices:manage` for design, cloning, dictionaries and readiness refresh; `pnpm generate:dialogue` for explicitly authored multi-speaker turns.
