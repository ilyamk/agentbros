# ElevenLabs dubbing

Use `pnpm dubbing` with a typed request. Create names the first target language and prepays it once. Resume the same operation/binding. Additional languages and regeneration have separate reservations. Enterprise edits require the reviewed revision. Refresh observed revisions before localisation review; stale targets block review/render. Source-timed VTT is not dubbed word timing.
