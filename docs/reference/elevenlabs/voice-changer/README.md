# ElevenLabs voice conversion

Use `pnpm audio:transform` with task `voice-change`, an existing voice ID and an exact language/model. Preserve the original. The derived take needs its own timing and clock review even when the duration matches. Voice conversion does not establish anonymity or create a clone.
