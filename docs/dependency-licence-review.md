## Scope and remaining obligations

- Applies to the Licensor distributing this repository's own source, dependency manifests and collected notices under the Business Source License 1.1 (BUSL-1.1) and under the Licensor's commercial licence; it does not convey node_modules or dependency executables.
- Every one of the 205 original findings has an exact-version record. Original missing/UNLICENSED declarations are retained; package-specific upstream evidence supplies the separately documented terms.
- No global SPDX allowlist expansion, rightsholder waiver or human legal approval is implied. New versions, changed artefacts, dependency patches or a changed use require fresh review.
- Docker images, installers, redistributed node_modules, browser bundles and embedded WASM/native binaries are outside this assessment. Remotion compositor GPL/FFmpeg and Mediabunny native codec source/build/relinking obligations remain open for those distributions.
- Each user must separately satisfy Remotion v4 licensing eligibility/company entitlement and GSAP permitted-use restrictions. Neither BUSL-1.1, its Additional Use Grant nor the Licensor's commercial licence grants any right in a dependency; they cover only code the Licensor may license.
- Reassessed on 2026-11-17 for BUSL-1.1 and commercial distribution of the Licensor's code, with the GPL-3.0-or-later Blender code as a separately licensed component, against the archives and evidence verified on 2026-11-15. No reviewed package carries copyleft that reaches the Licensor's BUSL-1.1 code: MPL-2.0 is file-level, the selected EPL-2.0 option of elkjs is module-level, and the GPL/LGPL code inside Remotion compositor and Mediabunny encoder payloads stays in separate programs or replaceable modules that this source distribution does not convey. No package is blocked.
- Each version of the Licensor's code also becomes available under AGPL-3.0-or-later on its Change Date. That does not change any dependency's terms; the Remotion License and the GSAP Standard License are not open-source licences, and anyone distributing converted code under the AGPL assesses those dependencies against the AGPL separately.

Runtime authorisations are separate, explicit owner decisions on the exact archive-bound package record. They apply only to the stated unmodified integration and selected licence; source-only technical reviews do not grant runtime or redistribution approval.
