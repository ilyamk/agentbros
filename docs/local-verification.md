# Local source verification

Run `pnpm lint` (or `pnpm exec tsx scripts/lint-project.ts`) before delivery. This command emits the standard one-line JSON envelope; violations return `VALIDATION` with `details.findings` containing relative file, line, column and rule. `--help` works offline. `--root` selects a trusted local checkout or fixture; no source is modified and no API is invoked. `--project <id>` also lints the git-ignored `src/projects/<id>` with the render rules (these fail) and slop signatures (advisory `metadata.slop`); the film chain's animatic and build steps run the same rules as their `project-lint-clean` done check, each finding a `file:line CODE: message. Fix: …` line. Render rules include `STATIC_PATH` (a bare `projects/…`, `shared/…` or `public/…` path as a media `src` without `staticFile()`) and `CSS_BG_IMAGE` (`background-image`/`background` with `url()`; gradients pass).

The checker uses the installed TypeScript 7 AST API; its unstable API import is confined to `src/lib/verification/lint.ts`. It scans at most 2,000 TypeScript files, 2 MiB each, depth 20, and rejects source-tree symlinks. Missing lint trees are errors rather than silently incomplete scans.

Render checks apply only to `src/components` and `src/templates`: forbidden animation libraries, render timers/RAF, R3F `useFrame` including imports/aliases, native image/video/audio JSX, animated Tailwind class names, CSS animation/transition style properties (including local variable styles), and active JSX style blocks. Remotion frame-driven animation and background-job timers remain legal.

Subprocess checks apply to those trees, `src/lib`, `src/mcp` and `scripts`: imported child_process `exec`/`execSync` fail; argv-based `spawn`/`execFile` pass when shell stays disabled. Explicit shell options, including local options variables, fail. These checks are static review aids, not a security sandbox or complete interprocedural taint analysis; dynamically loaded modules and arbitrary computed CSS still need code review.

`tests/lint.test.ts` executes malicious and legal source fixtures, verifies literal malicious-looking subprocess arguments without invoking a shell, and calls every production TypeScript entry point's help with API credential environment variables removed. Existing large-envelope and MCP bridge tests cover bounded output transport. `src/mcp/stdio.ts` intentionally implements the official MCP JSON-RPC protocol and is outside the production script envelope contract; see [mcp.md](mcp.md).
